{# ルール #}
テストのルール
  • 1回のテストで1つのスキルを確認します。問題は4択で全{{ rules.total }}問 （{% for r in rules.rows %}Lv{{ r.level }} {{ r.count }}問{% if not loop.last %}・{% endif %}{% endfor %}）。 やさしい問題（Lv1）から順に出題します。
  • 1問ずつの制限時間があります（{% for r in rules.rows %}Lv{{ r.level }} {{ r.limit }}秒{% if not loop.last %}・{% endif %}{% endfor %}。合計 約{{ rules.minutes }}分）。 0秒になると自動で次の問題へ進み、時間内に回答しなかった問題は不正解になります。ページを再読み込みしても残り時間は戻りません。
  • 1問ずつ回答し、前の問題には戻れません。選択肢の並びは受験ごとに変わります。
  • 途中で画面を閉じた場合は、開き直すと続きから再開します。ただし開始から 約{{ rules.deadline_minutes }}分を過ぎると自動で終了し、未回答の問題は不正解として採点します。
  • 判定: あるレベルの正答率が{{ rules.pass_rate }}%以上で、それより下のレベルもすべて合格していれば、そのレベルに合格です。合格した最も高いレベルがテストの結果です（Lv1が不合格なら Lv0）。
  • 結果のレベルが今の到達度より高いときだけ、到達度に自動で登録します。今の到達度が下がることはありません。
  • 同じスキルの再受験は、前回の受験開始から{{ rules.retake_days }}日後からできます{% if rules.retake_days == 0 %}（現在は制限なし）{% endif %}。受験中のテストは1つだけです。
  • 受験中は、ほかのタブやアプリに切り替えないでください。画面から離れた回数は記録され、マネージャーが確認します。問題文のコピーはできません。
  • 結果の画面には、レベルごとの正解数と結果のレベルだけを表示します（各問題の正解は表示しません）。
テストで判定できるのは Lv{{ rules.top_level }}（{{ scale[rules.top_level] if rules.top_level < scale|length else '' }}）までです。 Lv5（{{ scale[5] }}）・Lv6（{{ scale[6] }}）と、コンセプチュアルスキル・ヒューマンスキルは、これまでどおりマネージャーが評価します。 4択問題で確かめられるのは知識と判断の一部で、実際に作れること・教えられることまでは測れません。
